# data

English | [简体中文](README.md)

Test data directories:

- `seed/`: small, deterministic, committable seed data (smoke profile, 100,000 rows by default).
  Rebuild with `01_generate_tables.py --profile smoke --out data/seed --force`.
- `generated/`: 1 GiB scale data generated by `scripts/data-gen/`, always reproducible and not
  committed.

Conventions:

- All generation uses fixed random seeds for reproducibility;
- The three primary tables `orders`, `customers` and `payments` each hold at least 1 GiB of
  uncompressed logical data;
- Generated data keeps CSV/JSONL files and a `sha256` manifest per table;
- Incremental data is stored separately: `delta_insert.csv`, `delta_update.csv`,
  `delta_delete.csv`;
- Large files exist in one place only; each system loads them through scripts instead of keeping
  duplicate raw copies.
